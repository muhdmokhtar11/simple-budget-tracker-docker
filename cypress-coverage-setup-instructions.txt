Run E2E Tests: Execute the npm run ci:e2e:run command, which starts the server (using the instrumented .jar) and runs the Cypress tests against it. Ensure this step waits for the server to be healthy before starting the tests.

- name: 'E2E: Upload Coverage Reports'
